# non-ported: extensions/query

Source: `packages/client/tests/functional/extensions/query.ts`

Every test in this file exercises the Prisma Client `$extends({ query: {...} })` query-component
extension mechanism (middleware-style interception of operations, args mutation/isolation, result
override/mutation, `$allModels`/`$allOperations` scoping, composition with result extensions).
Prisma 8 has no `$extends` client-extension surface (zero hits for `$extends`/`getExtensionContext`/
`defineExtension` across `packages/` outside node_modules/dist; `packages/3-extensions/` is database
extensions, not client extensions). The subject of each test IS the query-extension mechanism itself.

- `packages/client/tests/functional/extensions/query.ts` › `extending a specific model query` — subject: a query component extension intercepts and modifies results for a specific model operation — non-ported (no `$extends` client-extension surface; subject is query component extension intercepting a specific model operation)
- `packages/client/tests/functional/extensions/query.ts` › `top to bottom execution order` — subject: multiple query extensions intercepting the same operation execute top-to-bottom (outer-to-inner) — non-ported (no `$extends` client-extension surface; subject is query extension middleware execution order)
- `packages/client/tests/functional/extensions/query.ts` › `args mutation isolation` — subject: query extensions receive isolated argument copies and mutations do not bleed between extensions — non-ported (no `$extends` client-extension surface; subject is argument isolation between query extension middleware layers)
- `packages/client/tests/functional/extensions/query.ts` › `args mutation accumulation` — subject: mutations made to args by one query extension are visible to the inner query — non-ported (no `$extends` client-extension surface; subject is argument mutation accumulation through query extension middleware)
- `packages/client/tests/functional/extensions/query.ts` › `query result override with a simple call` — subject: a query extension overrides the result of an operation by returning a custom value — non-ported (no `$extends` client-extension surface; subject is result override via query extension)
- `packages/client/tests/functional/extensions/query.ts` › `query result override with extra extension after` — subject: result override when an additional extension is applied after the overriding extension — non-ported (no `$extends` client-extension surface; subject is result override in query extensions with extensions applied after)
- `packages/client/tests/functional/extensions/query.ts` › `query result override with extra extension before` — subject: result override when an additional extension is applied before the overriding extension — non-ported (no `$extends` client-extension surface; subject is result override in query extensions with extensions applied before)
- `packages/client/tests/functional/extensions/query.ts` › `query result mutation with a simple call` — subject: a query extension mutates (not replaces) the result — non-ported (no `$extends` client-extension surface; subject is result mutation via query extension)
- `packages/client/tests/functional/extensions/query.ts` › `query result mutation with multiple calls` — subject: result mutation across multiple chained query extensions — non-ported (no `$extends` client-extension surface; subject is result mutation accumulation across multiple query extensions)
- `packages/client/tests/functional/extensions/query.ts` › `extending with $allModels and a specific query` — subject: a `$allModels` query extension scoped to a specific operation works correctly — non-ported (no `$extends` client-extension surface; subject is `$allModels` query extension scoped to a specific operation)
- `packages/client/tests/functional/extensions/query.ts` › `extending with $allModels and $allOperations` — subject: a `$allModels`/`$allOperations` query extension intercepts all model operations — non-ported (no `$extends` client-extension surface; subject is `$allModels`/`$allOperations` universal query extension)
- `packages/client/tests/functional/extensions/query.ts` › `extending with specific model and $allOperations` — subject: a specific-model/`$allOperations` query extension intercepts all operations for that model — non-ported (no `$extends` client-extension surface; subject is specific-model/`$allOperations` query extension)
- `packages/client/tests/functional/extensions/query.ts` › `errors in callback` — subject: errors thrown inside a query extension callback propagate — non-ported (no `$extends` client-extension surface; subject is error propagation from within query extension callbacks)
- `packages/client/tests/functional/extensions/query.ts` › `errors in with no extension name` — subject: errors from unnamed query extension callbacks propagate — non-ported (no `$extends` client-extension surface; subject is error propagation from unnamed query extension callbacks)
