# Non-ported — issues-21136-extensions-mocking-library

Matrix: SQLite-only (`optOut` from all other providers), `skipDb: true`. All 6 tests are type-level only — they verify that `prisma.$extends({...})` result types are correctly inferred when the extended client is wrapped in a deep-mocking-library proxy (`DeepMockProxy<T>`), covering both a full model-override extension and an empty extension. Prisma 8 has no `$extends` surface, so there is no extended-client type to feed into the mock proxy → non-ported.
