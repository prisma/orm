- `packages/client/tests/functional/issues/29212-array-push-regression/tests.ts` › `correctly pushes to array field` — `update({ data: { tags: { push: ['foo','bar'] } } })` atomically appends elements to a scalar array column — the subject is the `{ push: [...] }` atomic array-append update operator; Prisma 8's `MutationUpdateInput` is `Partial<DefaultModelRow>` (plain scalar values only) and has no `{ push: [...] }` / `{ set: [...] }` / atomic-operator form for array fields. Writing a faithful `update({ tags: { push: ['foo', 'bar'] } })` call is a type error and has no runtime equivalent in Prisma 8 today.
