# Non-ported — raw-queries/typed-results

The subject of every test is `$queryRaw` (tagged-template form: `` prisma.$queryRaw`SELECT …` ``) returning typed rows from the database. Prisma 8 runs raw SQL through ``db.raw.sql`…` ``, but the caller declares each result column's codec (`.returnsRow({ ... })`), so the mechanism under test, result types inferred from the database's response, has no equivalent.

- `packages/client/tests/functional/raw-queries/typed-results/tests.ts` › `simple expression` — verifies `$queryRaw\`SELECT 1 + 1\`` returns `2` — `$queryRaw` tagged-template absent in Prisma 8
- `packages/client/tests/functional/raw-queries/typed-results/tests.ts` › `query model with multiple types` — verifies `$queryRaw\`SELECT * FROM "TestModel"\`` returns typed row with all scalar types — `$queryRaw` tagged-template absent in Prisma 8
- `packages/client/tests/functional/raw-queries/typed-results/tests.ts` › `query model with a BigInt = 2147483647 (i32)` — BigInt i32 boundary via `$queryRaw` — `$queryRaw` tagged-template absent in Prisma 8
- `packages/client/tests/functional/raw-queries/typed-results/tests.ts` › `query model with a BigInt = -2147483647 (-i32)` — negative i32 boundary via `$queryRaw` — `$queryRaw` tagged-template absent in Prisma 8
- `packages/client/tests/functional/raw-queries/typed-results/tests.ts` › `query model with a BigInt = MAX_SAFE_INTEGER` — MAX_SAFE_INTEGER via `$queryRaw` — `$queryRaw` tagged-template absent in Prisma 8
- `packages/client/tests/functional/raw-queries/typed-results/tests.ts` › `query model with a BigInt = -MAX_SAFE_INTEGER` — negative MAX_SAFE_INTEGER via `$queryRaw` — `$queryRaw` tagged-template absent in Prisma 8
- `packages/client/tests/functional/raw-queries/typed-results/tests.ts` › `when BigInt value is not a safe integer > query model with a BigInt = MAX_SAFE_INTEGER + MAX_SAFE_INTEGER > BigInt is natively supported` — overflow BigInt via `$queryRaw` — `$queryRaw` tagged-template absent in Prisma 8
- `packages/client/tests/functional/raw-queries/typed-results/tests.ts` › `when BigInt value is not a safe integer > query model with a BigInt = MAX_SAFE_INTEGER + MAX_SAFE_INTEGER > BigInt is not natively supported` — js_d1-only overflow-rejection via `$queryRaw` — `$queryRaw` tagged-template absent in Prisma 8 (also driver-adapter-specific)
