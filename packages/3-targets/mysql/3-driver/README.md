# @internal/driver-mysql

MySQL runtime and control drivers for Prisma 8, built on the `mariadb` package (3.5.4 or later).

## Package Classification

- **Domain**: targets
- **Layer**: drivers
- **Plane**: multi-plane (shared, migration, runtime)

## Purpose

Connects the runtime and the control plane to a MySQL server and hands codecs every row value as text, bytes or null ([ADR 155](../../../../docs/architecture%20docs/adrs/ADR%20155%20-%20Driver%20Codec%20Boundary%20and%20Lowering%20Responsibilities.md)).

## Responsibilities

- **Prepared statements**: every statement the runtime driver runs, raw SQL included and even with no values, is a server-side prepared statement (`prepare` then `execute` or `executeStream`), so a value never travels inside the SQL. A raw `START TRANSACTION` or `LOCK TABLES`, which MySQL does not prepare, fails with MySQL's error 1295 as a `SqlQueryError`. `src/core/positional-params.ts` writes the adapter's numbered `?N` as MySQL's positional `?` and orders the values to match, a value repeated as often as its `?N` appears; a bare `?` takes the values in order. It reads the SQL with the target's lexer, so a `?` inside a quoted string, a backtick identifier or a comment stays text, and an executable `/*!` comment is refused. A statement whose placeholders and values do not match, by the lexer or by the count MySQL reports when it prepares the statement, raises `RUNTIME.PARAM_PLACEHOLDER_MISMATCH`. MySQL's own refusal of a value, such as a `LIMIT` that is not an integer, is a `SqlQueryError` like any other server error. `multipleStatements` and every option that rewrites SQL on the client stay off.
- **Values**: an integer number within the signed 64-bit range is sent as a BIGINT, because the package sends a number as INT only below 2^31 - 1 and otherwise as DOUBLE, which MySQL refuses in `LIMIT`. Any other finite number, a whole number such as `1e20` included, is sent as the DOUBLE it is. A `bigint` must fit a signed BIGINT and is refused otherwise: below -2^63 the package throws inside its socket write, which crashes the process, and at or above 2^63 it sends the digits as a DECIMAL, so the parameter's type would change with its value. A `Uint8Array` is sent as a Buffer over the same bytes. A `Date` is refused: the package encodes it in the process's local time zone, and the MySQL codecs send dates as text. A refused value (a `bigint` out of range, a `Date`, an object, an array, `NaN` or an infinity) raises `RUNTIME.ENCODE_FAILED` with `paramIndex` and `received`. The package's `logParam` is off, so values never appear in error messages.
- **Prepared-statement cache**: off by default (`prepareCacheLength: 0`), so each statement is prepared, run and closed. `statementCacheSize` in the URL turns it on with that many statements per connection, at most 1,000, so a pool of 10 connections stays under MySQL's server-wide limit. Two risks come with it: MySQL caps open statements across all connections (`max_prepared_stmt_count`, 16,382 by default), and reaching the cap fails with MySQL's error 1461 as a `SqlQueryError`; and since MySQL 8.0.22 a cached statement keeps the parameter types of its first run, so a value sent later as another type is converted.
- **Connection URL** (`src/core/connection-options.ts`): reads `ssl` (`true`, or a JSON object of `ca`, `cert`, `key`, `passphrase`, `servername` and `rejectUnauthorized`), `connectTimeout` (ten seconds by default), `allowPublicKeyRetrieval` (off by default; MySQL 8.4's `caching_sha2_password` needs it, or TLS, over plain TCP), `connectionLimit`, `poolTimeout` (milliseconds, ten seconds by default) and `statementCacheSize`, validated with arktype, and refuses any other parameter with `RUNTIME.BINDING_INVALID`. The refusal lists the parameters the driver accepts, and for a Prisma 7 engine parameter (`connection_limit`, `pool_timeout`, `connect_timeout`, `sslcert`, `sslidentity`, `sslpassword`, `sslaccept`, `socket_timeout`, `statement_cache_size`) it names the accepted parameter that replaces it, if any. A refused value names its parameter and the form it must take. No error copies the URL or any parameter's value, since the URL carries the password and TLS keys. Every connection uses utf8mb4 and a `charset` parameter is refused: the driver reads each statement as utf8mb4 to find its placeholders, and MySQL must read it the same way.
- **Session setup** (`src/core/session-setup.ts`): the package runs it once on each physical connection (`initSql`). It clears `NO_BACKSLASH_ESCAPES` and `ANSI_QUOTES`, so MySQL reads quoted text as the driver's lexer does, and sets UTC and utf8mb4. There is no reset on release: a raw `SET` stays on the connection for its lifetime, as on Postgres. The pool rolls back a transaction left open on a connection it gets back.
- **Rows**: both drivers return every row value in the form [ADR 155](../../../../docs/architecture%20docs/adrs/ADR%20155%20-%20Driver%20Codec%20Boundary%20and%20Lowering%20Responsibilities.md) sets: text, bytes or `null`. One `typeCast`, `readTextOrBytes` in `src/core/text-or-bytes.ts`, set in the connection options, reads a binary string or blob, BIT and GEOMETRY as a Buffer and every other column as text. Over the text protocol that text is what MySQL sends. Under a prepared statement MySQL sends numbers, dates and times in binary and the package writes them as text: an integer as its digits, a FLOAT as the decimal text of the double it widens to (`0.1` reads `0.10000000149011612`), a DOUBLE as JavaScript prints it, DATE and DATETIME as MySQL prints them, TIME with six fraction digits when it has any. DECIMAL, JSON, ENUM and SET (`a,b`) arrive as MySQL's text.
- **Errors**: a lost connection (the package marks it fatal, error 45009) is `DRIVER.NOT_CONNECTED` and its connection is destroyed; any other error MySQL reports becomes a `SqlQueryError` carrying its SQLSTATE, with a `detail` that explains errors 1295 and 1461; a sign-in that needs the server's public key (the package's error 45044: the account uses `caching_sha2_password` or `sha256_password`, the server asks for the full password exchange, and the connection has no TLS) is `DRIVER.CONNECTION_FAILED` with a fix that names `allowPublicKeyRetrieval=true` and TLS; a pool that gives no connection within `poolTimeout` is `DRIVER.CONNECTION_FAILED`, with the reason it could not connect; a failed control connection is `DRIVER.CONNECTION_FAILED` with the URL redacted.
- **Runtime driver** (`./runtime`): a `mariadb` pool. A connection goes back to the pool after each statement as it is; it is destroyed only when it is lost or broken, or when the caller stops reading a stream the pool lent it for while the rest of the result is still arriving. When the package has already received the end of the result, the driver drops the rows left in its buffer and returns the connection. MySQL does not say how many rows remain, so a result still arriving is not downloaded only to be thrown away; destroying a connection mid-result makes the package open one short-lived extra connection to send `KILL`. A connection the caller holds reads and drops the rest of a stream it stops early, so its session survives. The package runs a connection's statements one at a time in the order they are sent, as `pg` did for the Postgres driver: a statement, commit or rollback sent on a held connection or transaction while a stream on it is open waits for the stream to end. One awaited inside that stream's own loop never finishes, as on Postgres with a cursor. Transactions use the package's `beginTransaction()`, `commit()` and `rollback()`. `close()` waits for every connection and stream it has handed out, then ends the pool.
- **Control driver** (`./control`): one connection. A statement with values runs prepared. Any statement without values runs through the text protocol, a user's `rawSql` migration step included, because MySQL does not prepare some such statements, such as `START TRANSACTION` and `LOCK TABLES`. That is safe: a statement without values has nothing written into it, `multipleStatements` is off, and the connection is not shared. So a migration step can run `LOCK TABLES`, which the runtime driver refuses.

## Exports

- `./control`: the control driver descriptor and `MysqlControlDriver`
