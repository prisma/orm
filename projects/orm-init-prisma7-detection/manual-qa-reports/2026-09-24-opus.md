## Findings

| # | Severity | Finding | Status |
|---|---|---|---|
| F1 | 🛑 blocker | The remove command named `dotenv` although the project declared it before init, so following the advice removed the user's own dependency. | Fixed in 9b398a5518. |
| F2 | ⚠ should fix | A re-run replaced init's own `prisma.config.ts` without naming it in the re-init consent, because detection reports the renamed `prisma7.config.ts` as the Prisma 7 config. | Fixed in 25976f9383. |
| F3 | ⚠ should fix | Version skew between the CLI running init and the installed target package can refuse a valid schema. The branch CLI (based on `main` of 2026-09-16) refused `@default(false)` when run against the 2026-09-24 `dev` package, which expects the `dataTypeLookup` that `main` added. Merging `main` fixed the QA run. Published releases pin the toolchain inside `prisma` to the target package version, so matching `latest` releases agree; a user running an older CLI against a newer target package would get a false refusal. | Reported; accepted cost of the in-process check. |
| F4 | ℹ note | The `latest` `@prisma/orm-postgres` predates `prisma7Schema`, so until the next release every real user gets `CLI.INIT_PRISMA7_SOURCE_UNAVAILABLE` from the flag, or a fresh init from the question. | Expected; needs a release. |
| F5 | ⚠ should fix (pre-existing, engine) | After answered prompts, init prints "Done" and the process does not exit. See S12. | Engine brief updated. |
| F6 | ⚠ should fix (pre-existing, engine) | `--confirm` does not answer the consent in an interactive session (cause found in the engine's `consent`). Not re-driven here. | Engine brief. |
| F7 | ℹ note | When a refusal follows, the warnings collected during input resolution (for example the unchecked-schema warning) are not shown. | Open. |
| F8 | ℹ note | The typed consent was rejected once when the whole token arrived in one write; a person typing is unaffected. | QA artifact, likely. |
| F9 | ℹ note (pre-existing) | The `db sign` next step renders as a sentence followed by ".: prisma db sign". | Open. |
| F10 | ℹ note (pre-existing) | A re-run deletes the emitted contract; with `--skip-install` it is not re-emitted. | Open. |
