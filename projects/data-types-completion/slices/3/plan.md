## What the slice changes, in one example

```prisma
model Event {
  id Int      @id
  at DateTime @default(datetime`2024-01-01T00:00:00Z`)
}
```

On SQLite the column's data type becomes `sqlite/datetime`, stored as `text`. `contract.json`, the `DEFAULT` clause and every row hold one text, `2024-01-01T00:00:00.000Z`. `db verify` reads the reported default `'2024-01-01T00:00:00.000Z'` with the column's codec (`fromWire`, then `toDataTypeValue`) and compares it with the contract's value. `@default("2024-01-01T00:00:00Z")` is refused with a message that shows the tag.

## Halt conditions

In addition to the project plan's:

- A codec whose `fromWire` cannot read the value its column's JSON projection produces, for a built-in type.
- A reported default, for a type with a codec, whose literal body is not what the codec's `fromWire` reads for a row.
- A place that needs a default's SQL text synchronously, after dispatch e.
- A committed Postgres contract, other than one read from a Prisma 7 schema, whose stored value changes.
- An extension codec that cannot construct its values through its type.
