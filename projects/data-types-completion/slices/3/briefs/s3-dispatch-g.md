## Build

1. **Folder.** `upgrade-instructions/pending/data-type-values/app/` and `.../extension/`.
2. **Application script.** Idempotent, needs no database. It rewrites each stored SQLite contract and migration snapshot: each datetime and JSON column's `dataType` (`sqlite/datetime`, `sqlite/json`), their default values in the new stored form, and every hash that follows, as slice 2's script does. Tests for the script, including a second run that changes nothing.
3. **Application text.** Shows the PSL rewrite from quoted dates, times, intervals and bytes to tags, with the error message a user sees before the rewrite. Tells Postgres users that a contract emitted by an earlier release is refused when it stores a default in another spelling than its parameters give: `"1.5"` on `numeric(10,2)`, a padded `char` default, a time finer than its precision, or a date or time default in a spelling from before stored values had one form (`.000Z`, an offset `+01:00`, `12:34` without seconds, a space instead of `T`); `contract emit` and `db sign` fix it. Covers SQLite REAL and INTEGER columns holding text that is not a number, which `fromWire` now refuses; a two-dimensional text array, now refused; a SQLite BLOB column holding text or a number, which a flat read now refuses; `min` and `max` of `text[]`, which now return an array. For projects that read a Prisma 7 schema, it says that a `DateTime` default with more fraction digits than its column holds (`"2024-01-02T03:04:05.1234Z"` on a plain `DateTime`, which is `timestamp(3)`) is now refused instead of rounded, shows the message, and says to write the value PostgreSQL stores. Ends with `contract emit` and `db sign`.
4. **Extension text.** The four codec methods replacing `encode`, `decode`, `encodeJson`, `decodeJson`; `DataTypeValue` and `DataType.fromCodec`; parameter limits moving from codec to type; JSON projections read by `fromWire`; `emptyResultJson` renamed `emptyResultWire`. Each with a before-and-after code sample.

Re-record the golden planner test and list every DDL change; only the ones the project plan allows may appear.
