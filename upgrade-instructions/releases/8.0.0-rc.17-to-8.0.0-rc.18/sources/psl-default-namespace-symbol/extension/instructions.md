# The PSL symbol table places top-level declarations in the default namespace

`@prisma/orm-framework` publishes these modules as `@prisma/orm-framework/psl-parser`, `/config/config-types` and `/components/control`.

## `build-symbol-table-takes-default-namespace-id`

Pass the target's default namespace id: `context.defaultNamespaceId` in a contract source, `stack.target.defaultNamespaceId` from a control stack. A `ContractSourceContext` or `ControlTargetDescriptor` built by hand adds the same field (`'public'` for Postgres, `'__unbound__'` for SQLite and MongoDB).

```ts
const { symbolTable } = buildSymbolTable({
  documents,
  sources,
  defaultNamespaceId: context.defaultNamespaceId,
});
```

## `symbol-table-has-no-top-level`

Before:

```ts
for (const model of Object.values(symbolTable.topLevel.models)) visit(model, undefined);
for (const namespace of Object.values(symbolTable.topLevel.namespaces)) {
  for (const model of Object.values(namespace.models)) visit(model, namespace.name);
}
```

After:

```ts
for (const namespace of Object.values(symbolTable.namespaces)) {
  for (const model of Object.values(namespace.models)) visit(model, namespace.id);
}
```

`symbolTable.namespaces` includes the default namespace, which is also `symbolTable.defaultNamespace` and holds the top-level declarations together with the members of a `namespace public { … }` block. `topLevel.namedTypes` is `symbolTable.namedTypes`. Use `namespace.id` for a contract id; `namespace.name` is the PSL spelling, which differs only for the late-bound namespace (id `__unbound__`, name `unbound`, one symbol for both spellings). `namespace.declarations` lists the written blocks and is empty for a default namespace with none. A model, composite type or block resolution always has `namespace`, so `resolution.namespace?.name ?? fallback` becomes `resolution.namespace.id`.

## `repeated-extension-block-is-a-duplicate-declaration`

The symbol table reports the repeated block before any entity factory runs. Change the expected code for those inputs only; `PSL_DUPLICATE_EXTENSION_ENTITY` is still reported when two different blocks place an entity under one key in one namespace.

## `psl-default-namespace-schema-rules`

A name declared both at the top level and inside `namespace public { … }` (the default namespace on Postgres), or a `types { }` binding or namespace with the same name as a member of that block, is `PSL_DUPLICATE_DECLARATION`: remove or rename one. A top-level declaration named like the target's default namespace (`public` on Postgres; `unbound` or `__unbound__` on SQLite and MongoDB) is rejected with the same code: rename it, and on a model keep the stored name with `@@map`.
